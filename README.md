# Calculadora de Médias Escolares 🎓

Um programa simples de console desenvolvido em C para gerenciar notas de alunos. O sistema permite cadastrar múltiplos alunos, registrar suas notas, calcular a média final e determinar se foram aprovados ou reprovados.

## 🚀 Funcionalidades

- Cadastro dinâmico de quantidade de alunos.
- Leitura de nome e duas notas por aluno.
- Cálculo automático da média aritmética.
- Exibição de um boletim final com o status:
  - **APROVADO**: Média maior ou igual a 7.0.
  - **REPROVADO**: Média menor que 7.0.
- Limpeza de tela automática entre os cadastros para melhor visualização.

## 🛠️ Tecnologias Utilizadas

- **C**: Linguagem principal do projeto.
- **Localização**: Uso da biblioteca `<locale.h>` para suporte a caracteres em português (acentuação).

## ⚙️ Pré-requisitos

Para compilar e executar este projeto, você precisará de:
- Um compilador C (como o GCC ou MinGW).
- Sistema Operacional Windows (devido ao uso do comando `system("cls")`).
